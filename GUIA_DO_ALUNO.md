# Guia do Aluno — Aula 09

## Antes de começar

1. Execute `npm install`.
2. Execute `npm start`.
3. Confirme se a tela inicial do laboratório aparece.
4. Abra `src/App.js` e leia os comentários.
5. Depois, abra os arquivos de `src/components`.

## Como usar este starter

Todos os componentes já foram criados para evitar perda de tempo com a criação manual da estrutura de pastas. Eles retornam `null` propositalmente e, portanto, ainda não exibem conteúdo.

Cada arquivo possui um bloco de comentários com quatro tipos de informação:

- **Objetivo didático:** por que o componente existe;
- **Conceitos:** quais fundamentos serão praticados;
- **Comportamento esperado:** o que deverá ser construído;
- **CSS disponível:** classes já prontas para uso.

## O que não está pronto

- lógica dos componentes;
- state;
- props;
- eventos;
- listas;
- condicionais;
- comunicação entre componentes;
- integração dos exemplos no `App`.

Essas partes fazem parte do exercício.

## Regra de desenvolvimento

Faça uma etapa por vez e teste antes de continuar. O objetivo da aula é entender a evolução do código, não chegar rapidamente ao resultado final.

Sugestão de commits:

```text
feat: adiciona exemplo de assets
feat: implementa comparação de state
feat: renderiza lista de usuários
feat: adiciona renderização condicional
feat: demonstra uso de props
feat: cria componente reutilizável de carro
feat: adiciona exemplo de fragment
feat: demonstra children
feat: envia função por props
feat: implementa lifting state up
refactor: revisa organização dos componentes
```
